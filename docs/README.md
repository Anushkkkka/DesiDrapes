# DesiDrapes AI Commerce Platform

DesiDrapes is a production-style e-commerce platform prototype built with React, TypeScript, Node.js, Express, Prisma, PostgreSQL, Docker, and n8n automation.

## Milestone 1 delivered
- Monorepo structure created
- Frontend moved into a dedicated frontend workspace
- Backend foundation added with TypeScript and Express
- Prisma schema scaffolded for users, products, orders, payments, reviews, coupons, notifications, and audit logs
- Docker Compose foundation configured for PostgreSQL, Redis, backend, frontend, and n8n
- Environment example added

## Next milestones
1. Connect Prisma to PostgreSQL and generate the first migration
2. Add authentication and JWT flow
3. Implement Stripe checkout and webhooks
4. Add AI-assisted product workflows and n8n automations
5. Build admin dashboard and analytics UI
